# 实现结构

来源、理解、表达和外部交付各自有一个边界。当前支持单个 Bilibili 分 P、YouTube 视频和本地文件；输出复用同一份版本化笔记。

```mermaid
flowchart TD
  B[Bilibili / BiliLens] --> S[SourceRecord]
  Y[YouTube / yt-dlp] --> S
  L[本地视频] --> S
  S --> M[共享字幕 / 本地 ASR / 有限抽帧]
  M --> R[预算内阅读包]
  R --> A[Codex 实际读文字与图片]
  R --> E[独立 API 图文理解核心]
  W[本地网页 / 受控任务] --> P[独立进程 / 运行时配置]
  P --> E
  A --> N[StudyNote + 冻结证据]
  E --> N
  N --> H[离线 HTML]
  N --> D[Markdown + 相对路径图片]
  N --> F[飞书正文 / 图片 / 在线回读]
  U[运行锁 / 检查点 / 用量] -.-> M
  U -.-> R
  U -.-> E
  U -.-> N
  U -.-> F
```

| 模块 | 拥有的责任 |
| --- | --- |
| `sources/` | 平台识别、元数据、字幕、短期媒体访问、原视频时间链接 |
| `contracts.py` | 来源契约与 URL/时长边界 |
| `materials.py` | 素材准备、共享 FFmpeg/ASR、帧缓存、下一段运行 |
| `sampling.py` | 低分辨率稳定变化候选、均匀锚点与变化帧的混合选择、按时长限制密度 |
| `reading.py` | 字幕段 ID、联系表、细读包与展示预算预留 |
| `api.py` | 明确的模型配置、真实图文请求、字节限制和凭据安全传输 |
| `calls.py` | 发送前预算预留、durable 回执、响应缓存完整性与未知发送保护 |
| `engine.py` | Python/CLI 共用理解流程，概览/可选细读/总结，草稿校验后冻结与导出 |
| `product.py` | 回环 HTTP、受控任务、历史、同源会话、安全视图与下载 |
| `worker.py` | 通过标准输入接收当前任务配置，独立进程复用理解核心 |
| `web/` | 本地静态操作页、阶段、历史、受限笔记预览，无构建服务 |
| `locking.py` | POSIX/Windows 文件锁与目录同步能力，共用于命令和本地服务 |
| `run.py` | 文件、预算、时间轴、运行锁、命令活动记录 |
| `usage.py` | 阅读声明、完成状态、真实/估计/未知计数及账本去重 |
| `notes.py` | 内容、证据引用、快照、版本、各输出共用的范围与用量 |
| `delivery/` | HTML、MD、飞书表达；外部写入回执及恢复 |
| `cli.py` | 便携命令分派；原生素材/交付命令与独立模型入口 |

## 来源边界

适配器的 `resolve` 返回 `SourceRecord`；`media` 返回只用于当前 FFmpeg 调用的 URL/选项。CID、DASH、yt-dlp 原始 JSON 和签名 URL 留在适配器内部。`timestamp_url` 统一产生原视频跳转链接。只有 YouTube 分支按需检测 yt-dlp/EJS/JS runtime；其他来源不依赖它们。

`SourceRecord` 保存平台、公开视频身份/所选 part、标题、时长、字幕来源/语言及原始秒数。未知字幕保持缺失，不拿标题代替语音。源字幕、ASR、分段截取和配图使用同一原视频时间轴。

## 理解与证据边界

每段最长 30 分钟，材料在预设预算内；概览覆盖整段，关键步骤再局部细读。阅读包记录确切的 `segment_ids` 和 `frame_ids`。提取成功、展示预留、Agent 声明已读分别记录。声明不能证明事实正确，Agent 必须实际看图并核对解释。

独立 API 核心发送阅读包的真实 JPEG 和字幕，先概览、最多一组细读、再总结；不用第二套素材与导出实现。每次发送前保存预算和 marker，响应先落盘再解释。可核对的 API 材料提交与原生 Agent 声明分别保留 provenance；两者都不能证明语义正确。API 草稿在 `finish` 前验证引用与时间范围，总结调用也进入冻结用量。配置与具体限制见 [standalone-api.md](standalone-api.md)。

`finish` 关闭本次阅读并写一次历史视频账目。`continue` 从 remaining_range 创建独立新 run，不改旧范围、旧笔记或旧账目。不同 run 可以独立运行，同一个 run 的命令由锁保护。失败保存已完成素材；重试复用缓存。

StudyNote 的段落、列表、代码、公式、表格、图片节点带证据引用及 speaker/agent/uncertain 归属。保存时校验已读声明和时间范围；快照复制、校验配图哈希。版本不可覆盖，重复相同输入复用版本。只拿到笔记快照及其相对资源也能导出，原始 run 或媒体路径后来变化不会改旧输出。

## 交付与恢复边界

HTML、MD、飞书消费同一份笔记和证据，不重新转写、读图或调用模型。HTML 离线嵌图；MD 的相对资源随文件移动，纯文本模式保留图注和时间点。HTML/MD 保存可读公式源，飞书映射原生 LaTeX；复杂排版不承诺逐像素相同。

飞书只新建独立管理文档；目标可为 new 或明确的 folder token。外部写入前保存 durable inflight 回执，结果未知时先核对远端而不盲目重建。已知文档的图像通过图注定位和远端字节哈希恢复；无法确认则停在未完成状态。重复发布在线回读同一文档，并保留回执冻结的原交付计划。改排版不会覆盖用户后来添加的正文。

## 计量边界

usage.json 是 prepare 到 finish 的冻结窗口；activities.jsonl 记录每条本地命令的状态与耗时。原生 token 有本线程回执才记录，不包含 finish 后的 Agent 撰写/对话。独立 API 有各调用回执，总结也在窗口内；未知调用令整体相关计数保持 null，另列已知小计。阶段不可分离时不制造阶段数字。候选扫描、提取帧、已读帧、文字粗估、实际 token 与独立 API 费用分列。导出脚本零模型调用不等于后续对话零额度消耗。

本地 HTTP 入口管理一个活动分析任务，并以独立子进程调用同一 `analyze` 核心。密钥只通过标准输入传入，不进入命令参数、任务元数据或浏览器存储。服务锁与执行锁分别保护网页实例和收费任务；父进程退出后仍在运行的子进程不会因服务重启而被重复调度。

HTTP 只返回允许列表任务视图，隐藏本机路径与原始回执。下载仅限校验后的笔记及配图；Markdown ZIP 不包含原始素材或模型配置。预览采用受限 iframe，生成内容不能执行网页应用脚本。重启仅观察已有任务，显式恢复沿用核心缓存，未知发送继续阻止重发。

运行进度从现有素材、调用回执与冻结笔记推导，不制造总进度百分比。新增来源主要实现一个适配器和来源测试；新增交付主要实现一个 delivery 模块与契约/失败恢复测试。没有数据库或动态插件发现。

RedNote 适配器归一化单视频元数据，临时媒体流与访问 URL 只留在 source_access 上下文。可选 bridge 用标准输入连接显式配置的外部小红书 skill，读取一篇笔记后丢弃作者、评论及会话字段。来源、运行与冻结证据仅保留无查询参数的笔记身份；字幕缺失时复用已有本地 ASR。
