# 暖白讲义与光谱书签

本地网页与离线 HTML 围绕课程阅读排版。历史和章节使用书签形态；正文按解释的顺序连续阅读，图片、公式、代码和表格拥有各自的空间。视觉更新消费已有 StudyNote，不改变视频范围、证据、用量或内容版本。

## 配色与排版

| 用途 | 色值 |
| --- | --- |
| 暖白页面 | `#FFF9F1` |
| 纸面 | `#FFFFFF` |
| 正文 | `#2D343B` |
| 光谱点缀 | `#EF6548` / `#FDBF47` / `#8ACFBA` / `#9CABEF` |
| 操作与链接的深色 | `#9C3E25` / `#326858` |

光谱用于页边、分隔线和书签短边；长段落保持深色文字与浅色背景。状态同时显示文字。使用本机中文字体栈，封面可使用衬线字，正文约 17px、1.85 行高；不加载远程字体或 CDN；离线 HTML 不含脚本。

网页准备区放在全宽讲义上方，减少嵌入预览的宽度压力。离线目录在正常文档流中，窄屏自然换行；正文控制行长，课件图可以更宽，代码自动折行，表格可局部横向滚动。公式继续显示可读源码。

证据使用原生展开入口，保留材料编号与原视频时间链接。关键图保持原图与解释，范围和未知用量保持可见。打印使用白底和深色文字。

## 修改与检查

网页布局归 `video_notes/web/index.html` 与 `app.css`；离线结构归 `video_notes/delivery/html.py`，样式归 `assets/summary.css`。保留表单钩子、sandbox、安全转义与源链接校验。两个样式文件分别服务本机应用和自包含离线文件，不增加主题运行时。

用已有冻结笔记重新导出，检查长中文、标题、时间跳转、配图、列表、代码、公式、表格以及部分覆盖与未知费用。再检查网页的空状态、历史、完成结果、错误提示、键盘焦点与手机宽度。排版检查不调用模型或访问新视频。
